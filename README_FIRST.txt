MARTIN VELAZQUEZ PORTFOLIO WEBSITE - VERSION 3

This version specifically fixes:
1. 02 / Creator Collaboration: rebuilt as a clean two-column HTML layout with no cropped workflow image and no overlapping elements.
2. Affinity Consulting: artwork was re-extracted into two clean independent images, removing the stray cropped text and improving alignment.
3. Contact & Toolkit: the boat photo is now image-only; "Martin Velazquez" is real HTML text below it, so the name cannot be cropped.
4. Added anti-overflow rules and responsive breakpoints for desktop, tablet and mobile.

BEFORE UPLOADING
- Open index.html in Chrome/Edge.
- Resize the browser to confirm desktop and mobile layouts.
- Test the reel, LinkedIn, email and PDF links.

GITHUB PAGES
1. Create a PUBLIC repository named martin-velazquez-portfolio.
2. Upload the CONTENTS of this folder directly to the repository root.
3. Make sure index.html is visible at the top level of the repo.
4. Go to Settings > Pages.
5. Source: Deploy from a branch.
6. Branch: main. Folder: / (root).
7. Save and wait for GitHub to publish the site.

Do not upload the outer folder itself as a nested directory. index.html must stay in the repository root.
